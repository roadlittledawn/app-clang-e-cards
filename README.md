# app-clang-e-cards

Multi-tenant e-card CRUD application built with Next.js 15, MongoDB, AWS S3, and deployed on Vercel.

## Development

This project uses [SDD (Spec-Driven Development)](https://github.com/LiorCohen/sdd) for structured feature development.

To create a new feature:

```
/sdd I want to create a new feature
```
