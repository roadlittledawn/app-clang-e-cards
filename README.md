# app-clang-e-cards

[![Deployed on Vercel](https://vercel.com/button)](https://app-clang-e-cards.vercel.app)

Multi-user e-card app built with Next.js 16, MongoDB, AWS S3, and deployed on Vercel.

## Development

This project uses [SDD (Spec-Driven Development)](https://github.com/LiorCohen/sdd) for structured feature development.

To create a new feature:

```
/sdd I want to create a new feature
```
